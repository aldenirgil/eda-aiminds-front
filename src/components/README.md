# Components

Este diretório contém todos os componentes reutilizáveis da aplicação.

## Estrutura

```
components/
├── common/          # Componentes comuns (Button, Input, etc.)
├── layout/          # Componentes de layout (Header, Footer, Sidebar)
├── forms/           # Componentes de formulário
└── ui/              # Componentes de interface específicos
```

## Convenções

- Use PascalCase para nomes de componentes
- Cada componente deve ter seu próprio diretório
- Inclua testes para cada componente
- Documente props e comportamentos complexos
