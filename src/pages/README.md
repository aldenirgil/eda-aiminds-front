# Pages

Este diretório contém as páginas principais da aplicação.

## Estrutura

```
pages/
├── Home/            # Página inicial
├── Dashboard/       # Dashboard do usuário
├── Profile/         # Perfil do usuário
└── Error/           # Páginas de erro (404, 500, etc.)
```

## Convenções

- Use PascalCase para nomes de páginas
- Cada página deve ter seu próprio diretório
- Inclua componentes específicos da página no mesmo diretório
- Use lazy loading quando apropriado
